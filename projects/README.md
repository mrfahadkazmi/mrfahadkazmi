## What the evidence means

- **Source inspected:** relevant source files were available for static review.
- **Automated test passed:** an automated test actually completed successfully in the stated local environment.
- **Not verified:** no claim is made about a capability until it is tested.
- **Mock-based:** a test uses substitute services or files; it does not prove a successful live cloud transfer.

See [Testing and evidence policy](../docs/verification-method.md) for the process used here.

> Security: Source code, private configuration, access tokens, SSH keys, browser cookies, personal records, and third-party binary packages are **not** published in this portfolio. These project pages are case studies, not public open-source releases.
